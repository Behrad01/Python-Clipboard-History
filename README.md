# Python-Clipboard-History
A clipboard manager that saves everything you copy and lets you view your history with the press of a button.

## Features

- Saves everything you copy (Ctrl+C)
- Shows timestamp for each copied item
- Keeps last 5 items (configurable)
- Press Tab to show/hide the history window
- Saves history to a JSON file
